# **App Name**: SAILE Access Point

## Core Features:

- User Type Selection: Allows users to select their user type (Platform Admin, Institution Admin, or Staff) via tabs or selectable panels.
- Authentication: Authenticate users based on their email and password. Includes input validation.
- Redirection: Redirect users to their respective dashboards based on their user type upon successful login.
- Error Handling: Display clear and concise error messages for invalid login attempts or other authentication issues.
- Forgot Password: Provide a 'Forgot Password?' link that redirects users to a password recovery page.
- Branding and Welcome: Display the SAILE Financial Services Ltd branding and a short welcome message on the login page.

## Style Guidelines:

- Primary color: #34B4EB to convey trust and professionalism.
- Secondary color: #FFFFFF to create a clean and modern look.
- Third color: #FB1902 to highlight interactive elements.
- Body and headline font: 'Inter' sans-serif for a modern, machined, objective, neutral feel; suitable for headlines or body text
- Use simple, professional icons for form fields and user type selection.
- Mobile-first design with a clean, single-column layout for ease of use on all devices.
- Subtle transitions and animations for user interactions, such as tab switching and form validation.
